# Тестовые данные организаторов (кейс №2)

Таблицы из документа «Кейс_Цифровой_двойник_Тестовые_данные.docx», перенесённые в CSV (разделитель `;`, кодировка UTF-8):

| Файл | Содержимое |
|---|---|
| `lines.csv` | работа производственных линий: план, факт, время работы, загрузка |
| `downtime.csv` | простои оборудования: участок, оборудование, причина, длительность |
| `plan.csv` | производственный план на месяц по моделям |
| `quality.csv` | показатели качества: выпущено, брак, % брака |
| `targets.json` | дополнительные вводные: 2 смены по 8 ч, OEE ≥ 85 %, брак ≤ 2 %, простой ≤ 60 мин/сутки, план ≥ 5 500 авто/мес. `working_days_month` = 22 — допущение команды (рабочие дни октября 2026), в документе его нет |

Такие же CSV (те же заголовки) можно загрузить на вкладке «Данные АЛЛЮР» кнопкой «Загрузить CSV». После изменения файлов пересоберите `frontend/allur_data.js`: `python scripts/build_allur_data.py`.
